# Resto App
## Описание проекта
Проект [Preax](https://preax.ru/) — статический сайт ресторана на классическом стеке: без сборщиков, препроцессоров, библиотек и фреймворков.
## Стек технологий
HTML5, CSS3, JavaScript (ES2022) — без зависимостей.
## Функционал
При клике на карточку блюда открывается модальное окно, в которое подгружаются мок-данные из dishes.json. Если у блюда есть размеры и добавки, они отрисовываются как опциональные блоки, а итоговая цена пересчитывается при каждом изменении выбора.
## Итог
**Что реализовано:**  
  
✅ Семантическая верстка, теги `time` и `address`  
✅ SVG-спрайт для иконок  
✅ Pixel Perfect по макету  
✅ Декомпозиция CSS и JS по модулям  
✅ JS-фабрики для создания HTML-элементов  
✅ БЭМ-нейминг CSS-классов  
✅ Изображения в WebP с fallback на JPEG через `picture`

❌ Адаптива нет осознанно — не входил в задачи спринта
